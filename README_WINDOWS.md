# Examen Digital - Instrucciones para Windows

## Requisitos Previos

**Python 3.10 o superior** debe estar instalado en tu computadora.

### Como instalar Python:

1. Ve a: https://www.python.org/downloads/
2. Descarga la version mas reciente de Python 3
3. **IMPORTANTE:** Durante la instalacion, marca la opcion **"Add Python to PATH"**
4. Haz clic en "Install Now"
5. Una vez instalado, verifica abriendo una terminal y ejecutando:
   ```
   python --version
   ```

## Como ejecutar el examen:

1. **Copia toda la carpeta del proyecto** a tu computadora
2. **Abre la carpeta** donde copiaste los archivos
3. **Haz doble clic en el archivo `iniciar.bat`**
4. Espera unos segundos mientras se instalan las dependencias (solo la primera vez)
5. Se abrira automaticamente el navegador con la pantalla de inicio de sesion

## Datos de acceso:

- **Usuario:** Tu usuario (ej: `wesly.alvarado`)
- **Contrasena:** Tu contrasena (ej: `ALV0131`)
- **Codigo del examen:** `PER01`

## Si tienes problemas:

### "Python no esta instalado"
- Verifica que Python este instalado correctamente
- Cierra y vuelve a abrir la terminal
- Verifica con: `python --version`

### "No se puede abrir el navegador"
- Abre tu navegador manualmente
- Ve a la direccion: http://localhost:8080

### "El servidor no inicia"
- Verifica que no tengas otro programa usando el puerto 8080
- Cierra otras aplicaciones y vuelve a intentarlo

### El examen no carga o aparece error
- Verifica tu conexion a internet
- Intenta recargar la pagina (F5)
- Cierra el servidor (Ctrl+C) y vuelvelo a iniciar

## Nota importante:

- El examen tiene **70 preguntas** y una duracion de **120 minutos**
- Una vez iniciado, no puedes pausar el examen
